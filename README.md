# Capitalize Name - HubSpot

Este projeto tem como objetivo **atualizar os nomes dos contatos no HubSpot para que fiquem corretamente capitalizados** (primeira letra maiúscula em cada palavra).

## 🚀 Funcionalidades
- Busca contatos no HubSpot com nomes não capitalizados.
- Atualiza o nome do contato com a formatação correta.
- Utiliza a **API do HubSpot** para ler e atualizar dados.
- Evita duplicidade e mantém a consistência dos dados.

---

## 🛠️ Tecnologias Utilizadas
- **Node.js** (JavaScript)
- **Axios** (para requisições HTTP)
- **HubSpot API** (para manipulação dos dados)

---

## 📦 Pré-requisitos
Antes de executar o projeto, certifique-se de ter:
- **Node.js** instalado (versão 14 ou superior)
- Uma **chave de API do HubSpot** válida
- **Git** para controle de versão (opcional)
